# 灰雾诊断与30fps曝光范围修正

2026-09-19。用户照片显示斑块彩噪、低对比度；矩形为轮廓目标而非实心块。上一版实心面积分类不满足该实物，轮廓识别改进仍待实施；本轮先检查成像问题，未将难识别归咎于用户摆放。

## 实测
- 原AE请求/读回1776半行，已顶到RTL上限；VTS读回0x05DC=1500行，完整RAW30fps。
- 中心RAW均值约24.3；黑电平处理/增益后中心RGB均值约5.95/5.48/6.62，提亮后约35.69/32.81/39.63。统计在相近时间顺序采样，并非同一冻结帧。
- shadow_boost=1；阴影表最低非零区增益0x0600即6倍，并非模块旧注释所写4倍。
- 暂时tone0对照用户反馈“完全不行”；已恢复tone3，不将关闭提亮当作修复，也不将该反馈解释成已证明某唯一根因。
- 原始冻结稀疏Bayer数据已保存raw.json。

## 曝光范围依据与试验
同型号参考驱动sc431hai_cmos.c使用2×VTS半行单位；sc431hai_cmos.h给出FL_OFFSET_LINEAR=11。
当前帧长1500对应上界2989半行；本轮选2950，保留余量，不改变PLL/HTS/VTS。
先关闭AE并固定1776，再通过单总线拥有者的调试寄存器接口写入2950，实际编码00 B8 60并读回。
观测完整1440行RAW约30.13fps，未掉为半帧；中心RGB均值提高至约8.65/8.27/10.07。
据此统一扩大AE控制器、曝光写入器、主机参数校验上限到2950。没有放宽到未知帧长或任意曝光值。
若将来切换60fps/其他VTS，必须重新计算限制。更长曝光在暗处可能增加运动模糊，静止样本与运动场景需要分开验收。
