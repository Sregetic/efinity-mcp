# AI实体菜单、自检与结果显示

本轮实现用户指定的第1、2项。正式资源、部署和待验收项以PROJECT_MASTER_STATUS.md最新摘要为准。

## 操作

KEY0短按仍切模式，长按依次正常/MEDIAN/ZOOM/PAN X/PAN Y/SIZE/POS X/POS Y/AI/SELFTEST。KEY2、KEY3长按仍为冻结与历史。

AI页：KEY2循环OFF(0)、FIX(1)、AUTO(2)；KEY3请求一次。FIX只在请求时运行，返回实时也保持单次；AUTO保留几何引导。FIX使用已提交源ROI，ROI关闭时用[640,300,640,480]。先冻结，再缩放或平移，提交结束后回AI页按KEY3，源帧不换、render ID改变；纯几何调整不冒充processing context变化。开发工具view策略仍连续。

SELFTEST页：KEY2执行；启动也自动执行。三组固定灰度输入逐项检查128特征、32隐藏输出、4输出、8字FlyHash和80个Q14状态，另检查dot4/MulHi。参考数据从当前权重和主机定点模型生成；更新权重同时重新构建。自检使用局部数组，保存并重新发布最后完成相机任务的身份、分数、ROI和框，不替换相机张量、完成序号。

## 显示

AI IDLE/RUN/DONE/ERR表示分析执行；ST NONE/WAIT/PASS/FAIL表示定点自检。N为完成序号低16位，A为结果年龄；F/R/M为源帧、render ID、模型ID。TEST保留合成模型标记，不作为识别准确率。

US Ixxxx Hxxxx Nxxxx HEX为INT8、FlyHash、连接组的十六进制微秒；65535饱和，完整周期在DDR记录。最后完成任务的时间/序号/源帧/context作为一组保留。

状态文字按结果身份匹配，而框仍按身份+扫描frame_ok。ROI窗口在y=240时，扫描器到窗口首像素才置frame_ok；原来借这个逐像素信号判断页头新鲜度，导致同帧同配置也显示OLD。现在在vision_ai_bridge共享身份比较、分开发布两个判定，保留坏扫描禁止画框。
