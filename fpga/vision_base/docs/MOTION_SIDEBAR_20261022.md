# 按键菜单：运动提示（2026-10-22，离线候选）

运动提示接入当前中文两层菜单的“目标”分类，原八种显示模式和M7几何识别保持。不是替换模式或自动跟踪，没有让运动结果接管一键居中、ROI任务、AI或DDR调度。

## 板端操作

1. 长按KEY0打开一级菜单；用KEY2/KEY3选“目标”，短按KEY0展开。
2. 用KEY2/KEY3选第四项“运动提示”，短按KEY0进入编辑。
3. KEY2选“开启”，KEY3选“关闭”；短按KEY0确认。长按KEY0取消草稿，实际开关保持。
4. 长按KEY0逐级返回并关闭菜单。开启时，原调试HUD下方显示“运动向左 / 向右 / 向上 / 向下 / 静止 / 待判”。

开关与其他视频参数一样，在VS帧边界统一生效。方向与保持标记也按帧快照，避免同帧文字混用不同观测。关闭默认不显示新文字；开启后关闭菜单仍显示提示。冻结F1、历史F2、比较F3时暂停并清除运动状态、隐藏提示，返回F0后重新积累观测；菜单保存的开关选择保持。

## 提示含义和边界

使用当前视图在边缘检测前的灰度，按12×12网格、每格8×8采样求均值，运行整数ON/OFF时延相关。四次新观测形成一窗、两个同向窗口确认方向；短时缺少新证据最多保持700ms，文字明确显示“保持”。保持值不是新的识别结果，也不计为新的方向正确率。没有训练模型，不属于物体类别识别或果蝇连接组推理。

算法只观察当前画面，不判断是哪一个物体；已有ROI启用时观察该视图。移动摄像头、改变照明也可能触发。没有新增全图搜索、持续跟踪或宣称实际方向精度。当前帧池/源帧/配置身份和一键居中规则保持。

## 接口

- 侧栏现有17个条目，新增`SIDE_MOTION=16`，目标组连续为13–16；其他条目ID保持。
- `settings[31]`为运动开关，复用原32bit设置写入和VS提交握手；原31bit字段保持。软核/IP/cache和共享状态结构均未扩容。
- 侧栏开启时，原紧凑菜单字段不使用，UI字bit14承载条目bit4；条目低4位仍在bits29:26。视频域24bit映射保持。侧栏关闭时恢复原紧凑菜单语义，诊断解码不会把高条目位报告成旧AI菜单。
- `vision_sidebar_overlay`复用已有字体实例和未使用的状态载荷位，无新UI帧缓存；实际69条文本、121个汉字，中文ROM仍4RAM，整个侧栏字体仍5RAM。
- 运动只旁路观察灰度。关闭侧栏或选择新条目不改变M0原图ISP旁路；显示和RGB24快照继续使用同一最终输出。

## 资源和验证

最终整机59878/60800 XLR、249/256 RAM、63/160 DSP，余922 XLR、7RAM、97DSP；WNS+0.237ns、WHS+0.027ns，未分配核心引脚0。比接入前57745/246/62新增2133 XLR、3RAM、1DSP。第一版运动整机60648/247/63；将新增模块的列历史/采样累加改为同步小RAM，并按输入上界收紧内部累加器，整机回收770 XLR、多用2RAM，没有删现有功能。图像快照仍5RAM。

完整相机DDR程序185888B（比对称居中版增加160B），BSS66104B保持；紧凑救援6820B在8KiB内。没有把新救援镜像写入CPU ROM；现有救援程序加载新DDR应用即可进入新菜单。

离线证据：RV32I4664断言、636组居中几何与12组诊断向量；VS原子开关和条目高位CDC；62组核心参考、864网格均值和57项显示读出；24幅对齐灰度光栅/八模式463059周期RGB与同步不变；六种中文状态及保持字、4007168个新UI外像素和96个字符；原侧栏5936988个外部像素保持。融合、边缘覆盖、前端和RGB24行快照另有定向回归。原完整19核心/38视频套件本轮未全量重复执行，合成结果不计实物准确率。
