## 按键操作

使用现有 KEY0、KEY2、KEY3，KEY1 仍为复位。短按约 0.2 秒后松开，长按约 1 秒。

| 状态 | KEY0 短按 | KEY0 长按 | KEY2 短按 | KEY3 短按 |
|---|---|---|---|---|
| 侧栏关闭 | 原八种显示模式切换 | 打开侧栏 | 原阈值 / 历史索引操作 | 原阈值 / 历史索引操作 |
| 侧栏列表 | 进入选中项的编辑 / 确认页 | 关闭侧栏 | 上一项 | 下一项 |
| 编辑 / 确认页 | 提交并返回列表 | 取消草稿并返回列表 | 增加 / 开启 | 减少 / 关闭 |

KEY2 长按仍切换 F0/F1，KEY3 长按仍按原 F1/F2/F3 规则工作，侧栏打开时也保留。F2 静态历史 I0–I5 和 I6 自动播放保持；浏览历史索引前先关闭侧栏。原诊断命令 `0x61` 保留旧菜单页接口，`0x62` 保留同一套按键事件入口。

设置先存为草稿，确认前视频参数和已提交 ROI 保持。确认后复用原参数帧边界提交、ROI 渲染及显示切换握手，不在像素扫描中途改几何。

## 侧栏项目

| 菜单 | 用途 / 数值 |
|---|---|
| MODE | 0 原图、1 灰度、2 Sobel、3 分屏、4 Sobel 叠加、5 Canny、6 Canny 叠加、7 SHAPE |
| THRESH | 当前模式的阈值；Sobel / Canny 分开保存，16–2047、步进 16；SHAPE 为 1–255 |
| MEDIAN | 中值开关，0 / 1 |
| ZOOM | 改源裁剪大小；显示源 ROI 宽度，常规全幅依次 1920 / 960 / 480 / 240 |
| PAN X / PAN Y | 移动源裁剪窗口，每次 32 / 16 个源像素 |
| SIZE | 改输出窗口大小，显示输出宽度 |
| POS X / POS Y | 移动输出窗口位置，每次 32 / 16 个显示像素 |
| AI | 0 OFF、1 FIX 单次、2 几何引导 AUTO |
| RUN AI | 确认后提交一次分析；原来为 OFF 时切到 FIX 单次 |
| SELFTEST | 执行原定点自检，不代表实物识别准确率 |
| MODEL | 0 BASE、1 FOMO；完整相机应用支持，基础控制应用跳过此项 |
| CENTER | 使用一个新目标结果，自动居中并放大一次 |
| TARGET Z | CENTER 的倍率上限：0 自动、1 / 2 / 4 / 8；大目标会降低实际倍率以保留整体 |
| FULLVIEW | 确认后恢复全幅源、全幅输出、零偏移，退出 ROI，并取消待执行的居中 |

屏幕使用原有 ASCII 字库，数字为十进制。Canny 的请求阈值与实际噪声下限仍按原 OSD 的 R / T 分别显示。

选中 SELFTEST 时侧栏页脚显示 `ST NONE/WAIT/PASS/FAIL`，AI 关闭时也可查看。AI / RUN AI / MODEL 的页脚显示 `AI IDLE/RUN/DONE/ERR`；这是任务运行状态，结果与当前画面的身份、年龄仍按原 OSD 判断。

## 单目标居中怎么用

1. 在 F0 实时或 F1 冻结下，让当前几何识别或 FOMO 得到一个有效目标。AI 关闭 / BASE 时使用现有几何检测；FOMO 已启用时请求一次新的 FOMO 分析，沿用当前 FIX / AUTO 的分析区域规则。
2. 长按 KEY0 打开侧栏，用 KEY2 / KEY3 选择 `CENTER`。
3. KEY0 进入确认页，再按 KEY0 确认；之后自动完成裁剪、缩放与定位，无需逐项修改 PAN / ZOOM / POS。
4. 等状态变成 `DONE`，长按 KEY0 收起侧栏。需要恢复时选择 `FULLVIEW` 确认。

这是一次性构图，不是连续跟踪。自动倍率在 1 / 2 / 4 / 8 中选择，给目标留边；目标靠近图像边缘时用黑边保留中心位置，不拉伸纵横比。水平中心取整误差至多 4 个显示像素。几何路径沿用原检测的候选范围和有效性规则；FOMO FIX 使用已提交源 ROI，ROI 关闭时仍为原固定分析区 `[640,300,640,480]`，不是新增全图搜索。

FOMO 等待时间仍由现有推理决定，未新增加速核；本轮没有重测板端耗时。当前模型精度和 A6 实物验收状态保持原记录，菜单和居中联调通过不等于识别精度通过。

| 状态 | 含义 |
|---|---|
| READY | 尚未请求 / 已恢复全幅 |
| WAIT | 等待新目标、AI 任务或原 ROI 提交完成 |
| DONE | 居中配置已被原渲染提交通路确认 |
| NO OBJ | 新结果中没有有效目标，当前构图保持 |
| BUSY | 已有 ROI 提交，或当前处于 F2/F3；返回 F0/F1 后再请求 |
| STALE | 等待期间模式、处理配置、源变换或结果身份改变，当前构图保持 |
| ERROR | 原 DMA / 推理 / 渲染通路报告错误 |

请求绑定源 `FRAME_ID`、渲染配置和处理 context；旧配置的目标框不用于调整新画面。几何检测在 AI OFF 时也更新，但 AI 结果显示的启用与身份检查仍保留。

这里保存的是本次识别结果的来源身份；F0 按该坐标调整实时构图，F1 则重渲染持有的同一原帧。两种情况都不会把旧 AI 框当作新配置下的新结果。

## 图像、资源和验证

侧栏在原图 / 模式选择之后叠加，不进入检测或 AI 输入；打开侧栏不切换原图 ISP 旁路。侧栏外 RGB 保持，整条显示 RGB / DE / HS / VS 统一增加 **1 个 148.5MHz 视频时钟，约 6.73ns**，不缓存整帧。原 RGB24 图像回读仍保留 5 块 RAM，可读到最终显示中的侧栏。

整机原生 P&R：**57821/60800 XLR、242/256 RAM、62/160 DSP**，相对 10-18 版增加 905 XLR、1 RAM、0 DSP，余 2979 XLR、14 RAM、98 DSP。最终 WNS +0.275ns、WHS +0.026ns，未分配核心引脚 0。首版文字表重复推断出额外 RAM，合并为一次共享查表后从 245 降到 242；没有删掉回读或既有功能。

离线证据：RV32I 实际固件控制逻辑 2525 个断言 / 407 组居中几何，另含已有平移缩放窗口的逆映射与诊断解码；19 项核心和 38 项视频回归通过。最终侧栏两幅完整 1080p 仿真共核对 3577692 个侧栏外有效像素，RGB 与同步一致；查表合并前后 262144 个时钟逐周期一致。图像回读测试保留 RGB888、192bit 行头、元数据和短行拒绝检查。

完整相机 DDR 应用为 184768B，比原版增加 5872B；BSS 仍为 66104B。片上 8KiB ROM、cache、CPU 和 CFU 配置保持。重新构建的紧凑启动 / 救援程序为 6656B，救援状态保留旧紧凑菜单；**新侧栏依赖配套的完整 DDR 应用，仅烧新位流后继续运行旧 Flash 应用不会出现新菜单。**
