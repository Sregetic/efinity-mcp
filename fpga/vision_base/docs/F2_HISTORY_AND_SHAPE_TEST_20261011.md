# F2静态历史浏览修复与SHAPE/FOMO实物测试准备

日期：2026-10-11。这里的F2指屏幕的历史回放状态，不是总目标表中编号F2的连接组研究任务。

## 原问题：F2持续循环，缺少静态历史帧浏览

- 用户现场反馈：KEY3长按进入F2后反复回放，选中历史帧没有保持为静态图。
- 记录时状态：只记录/核对代码，未修复。用户随后要求实施，修复后的部署与验收以PROJECT_MASTER_STATUS.md最新摘要及results/f2_static_20261011/REPORT.md为准。
- 原代码原因：`rtl/frame_memory_system.sv`的`history_tick`按显示`vblank`推进，在29/59时递增`play`；F2的`selected_age`使用`history_index + play`并对历史帧数回绕。因此在60Hz显示下约每0.5秒切换一张，短按KEY2/KEY3只改起始偏移，没有静态保持动作。`firmware/vision/control_service.h`只更新索引/模式，也未提供静态浏览。
- 当前统一帧池开启`pin_history`，保护六张历史帧；这段自动切换代码足以解释循环现象。暂未发现此次现象来自按键重复触发或历史帧覆盖的证据。
- 旧版回放本来就是自动播放，原操作指南“选择历史索引”没有说明仅选择播放起点；这是静态浏览交互缺口，不将过去六帧自动回放通过记为静态历史浏览通过。

实施交互：F2默认I0；I0–I5静态浏览，短按KEY2/KEY3前后切换；复用保留索引I6显式开启自动回放，离开I6就停止，未增加帧存储。KEY3长按仍到F3，F3仍只使用0–5并交替比较相邻帧；KEY2长按回F0。统一帧池与旧DDR分支、固件/无CPU控制、CLI及测试同步更新，原自动回放、F1冻结、F3比较与帧持有保护保留。

验收：无按键时选中源帧号至少10秒不变，移动镜头前物体也不改变该历史图；逐张切换能访问六张确定的历史帧；明确启动自动回放后才推进；F0恢复实时，冻结与ROI重渲染不换持有源帧，F3比较和扫描错误计数另行检查。

F1仍冻结最近原帧。F2/I0是所保存历史组的最新帧，I5最旧；I6是自动播放模式，不是第七张历史帧。自动播放保留原计时相位，进入I6时按当前相位继续，不承诺从I0重新开始。

实际SRAM验证：F2/I0源帧8388在60次采样、12.721秒内保持不变；I0–I5分别选择8388到8383；I6在4.933秒内访问六帧，KEY3短按回I5后3.672秒保持8383。显示第540行两次真实RGB回读间隔10.235秒、同源13865，5760字节差异0。实体事件队列的17项按键/ROI联调通过；人工电气按压和HDMI目视另验。当前资源60400XLR/252RAM/59DSP，较前版+318XLR、RAM/DSP无增长。Flash部署结果与完整证据见[修复报告](../results/f2_static_20261011/REPORT.md)。

## 先制作可重复摆放的测试卡

以下尺寸是制作起点，以屏幕中央区域内实际大小调整距离，不是已标定的工作距离或识别保证。

|卡片|简单做法|起始尺寸|
|---|---|---|
|空心圆|黑色哑光卡纸剪外圆，再剪去同心内圆，将完整纸环贴在白色哑光纸上；也可用圆规画两圈后填黑中间环带|外径8cm，环带宽5–8mm|
|空心矩形|黑卡纸剪一个矩形，再剪去内部矩形，留下闭合四边，贴在白纸上|外框10×7cm，四边宽5–8mm|
|实心圆/矩形|剪黑色圆片/矩形片贴在白纸上|与对应空心卡外形相同|
|实心三角形|剪完整黑色三角片贴在白纸上，供FOMO三角类测试；SHAPE不将其作为圆/矩形通过|底边约8cm、高约7cm|
|空白负例|不放任何目标的相同白纸|与其余卡相同底纸|
|断口负例|另复制一张空心卡，再在轮廓上去掉一段，保留原闭合卡|断口约5–10mm|

纸环和纸相框比反光金属垫圈、杯口、玻璃和透明胶更适合首轮定位问题。纸卡通过后，再测试哑光实体圆环/矩形框，记录实际物品、距离、光照和结果；纸卡通过不替代多种实物验收。标签写在识别区域外，裁剪保留完整闭合边，不留毛边、胶带反光或额外黑点。

## SHAPE板上操作与预期

1. 先用CAMERA确认对焦、光照与原图，再KEY0短按切到SHAPE；使用正常菜单，形状差值T先保留默认32，MED1作为首轮固定设置。
2. 将白底覆盖中央640×480虚线区域，四角16×16背景采样块都留白，一次只放一件目标；让目标占区域约1/3–2/3，外轮廓完整且四周留边。
3. 矩形先水平/垂直放正，卡面正对镜头；圆避免斜放成椭圆，尽量不给背景投明显阴影。固定目标后等待数帧再读结果。
4. 空白应为NONE；闭合圆期望CIRCLE/绿色框，轴对齐矩形期望RECT/蓝色框。实心和空心分别记录。断口和三角属于负例/OTHER检查，不要求它们被识别成圆或矩形。
5. 记录成功/漏检/误判、T/MED与摆放条件，随后分别测远近、平移、反色；先保持其他变量，再调整SHAPE差值阈值。该值不是Sobel/Canny阈值。

算法依据：`board/ti60f225_v4/rtl/vision/vision_shape_classifier.sv`使用四角背景估计、逐行闭合/连通检查与行跨度填充后的面积比；当前范围是单目标、均匀背景、轴对齐矩形。实物空心卡准确率仍待验收。

## 同一批物品用于FOMO，但验收不同

可以共用以上实心/空心卡片作为真实拍摄样本，保留圆、矩形、三角及空白类别。已实际查看`models/shape_fomo/test_vectors/circle_96.png`和`rectangle_96.png`：这两张联调图是深色实心圆/实心矩形，不是空心轮廓。交接包不含完整训练集，空心卡是否属于模型已学分布尚未确认；应让采样同学同时收集实心和空心、尺寸/角度/光照变化，训练与测试使用不同卡片/会话。

当前FOMO只有四组固定RGB96×96图片上板通过，约0.949秒/张；真实相机RGB ROI→FOMO→网格合并→OSD尚未接通，现有AI菜单执行的是原灰度INT8/FlyHash/连接组支路，不是FOMO。此时把卡放到镜头前可验SHAPE，但尚未直接得到实时FOMO结果。

FOMO拍摄验证路径：拍原始彩色图→保留完整目标的ROI/中心裁剪→按交接规范最近邻缩放RGB96×96、int8量化→主机推理→板上同输入逐值/耗时对照。模型输出12×12×4类别网格；同一物品可激活多个网格，阳性网格数不当物品数量。空心与实心各做独立结果统计，再验真实ROI和显示集成。

模型接口与当前接入证据见[SHAPE FOMO接入](SHAPE_FOMO_INTEGRATION_20261011.md)。F2修复没有变更SHAPE/FOMO算法或模型；上述实物验收状态保持独立。
