# XLR 优化：FlyHash DDR 邮箱与固件控制面

2026-10-07。本轮目标是减少逻辑占用，不调整图像处理算法、引脚、时钟、传感器、HDMI 时序或烧录默认值。当前 SRAM/DDR 运行配置保持，Flash 保持。新的源码和候选制品需配套部署；下述离线验证不登记为新位流的板上验收。

## 实施范围

- Sapphire 分支删除 USER2 0x51 逐字节特征写入及片上 64-byte 特征、256-bit hash 存储和宽选择器。0x50 静态任务改读 DDR 特征，0x54 仍由 CPU 通过原有 Canny 位图读口提取占据率。任务取消、CPU 复位、源帧/config/epoch/流错误变化及 nonce 拦截继续留在硬件。
- DDR 0x07620000 保存 128-byte 完整结果，0x07620100 保存 64-byte 静态输入，0x07620200 保存共享控制状态；均位于分析输入之后、arena 之前。CPU 写完整记录后发布 sequence，再确认邮箱完成。USER2 页29保留绑定状态，页30公布 DDR 地址；USER1 停核读取完整记录后恢复执行。
- 阈值下限16、步进16、上限2047、Sobel/Canny 独立设置、模式/中值/六帧历史选择、ROI 参数暂存/提交/预热/冻结重渲染决策迁入固件。硬件保留共享按键同步/消抖/长按检测、事件队列、VS 原子生效、渲染握手和显示位置帧边界发布。队列占2 RAM，满队列的实际输入丢失场景显式报告故障。
- `SAPPHIRE_ENABLE=0` 的实际旧构建入口继续使用原硬件控制/编码器；旧固件和 RTL 回读工具仍按实际版本分派。新固件通过共享 DDR 控制状态保持 USER1 加载 AI 程序前后的参数。首次初始化由配套 ROM 主程序完成，AI 入口核对控制 ABI。
- 配套 ROM 固件用 LTO 编译，保留原3840-byte应用限制，没有扩大 ROM/cache。AI 程序继续走现有 DDR 加载器。保留 freestanding memset，避免 LTO 删除编译器后续生成调用所需的符号。

## 完整构建实测（含物理路由占用）

|构建|XLR/60800|RAM/256|DSP/160|最终WNS/WHS ns|
|---|---:|---:|---:|---|
|原已部署调试版|60015|243|58|+0.093/+0.026|
|本轮最终候选|56818|245|58|+0.074/+0.026|

整机净释放 **3197 XLR**，占用从98.71%降到93.45%；剩3982 XLR和11 RAM。新增2 RAM用于控制事件FIFO，不是图像缓存扩大。map/interface/P&R/pgm全部PASS，未分配核心引脚0。最终时序读取Timing (Final)，没有将placement阶段−0.251ns误写成最终结果。

层级map指标：FlyHash邮箱FF1349→447、LUT845→163；原ROI+feature控制合计FF724→574、LUT772→462。FF/LUT指标不直接相加冒充XLR；3197是两项同时启用后的整机物理净变化，未用独立位流逐项归因。比赛版本轮没有重新构建，此处也没有将调试版数字冒充比赛版。

原始记录见resource_summary.json、release_snapshot.console.log、release_snapshot中的map/res/route/timing报告。候选bit/ELF和官方生成SoC只保留本机。

## 验证与证据

- `scripts/verify.ps1 -Suite quick`：18项 RTL 仿真通过，含新的邮箱与控制桥；计算租约、DMA、共享帧池/内存系统、缩放/渲染和 CDC 旧用例保留。
- 旧控制用例通过：独立阈值、16步进/下限、2047饱和、重复短按、消抖及 VS 生效。
- 控制桥异步时钟仿真通过：有序事件、短/长按、VS原子提交、冻结 CDC、任务握手、显示位置发布、错误绑定和队列溢出。
- 生产 C 控制策略在 RV32I QEMU 通过：单键与同时按键优先级、阈值/历史、等待参数提交、ROI 提交快照、预热、冻结重渲染、无效画布拒绝、旧渲染错误不吞掉新提交及关闭 ROI。
- FlyHash 生产 C 用相同 LTO 构建参数：32组特征、4幅480×270位图（含既有板上回读）与独立参考一致。DDR记录格式、帧绑定、未发布结果拒绝及新旧主机解码检查通过。
- 图像面板回归、DDR加载器回归通过。MCP 仓库测试71pass，1项Windows符号链接权限skip，实际MCP协议测试启用；`compileall src`通过。

首轮 `snapshot` 因生成块内 `gamma_vs` 前向引用形成未驱动局部网线，裁掉可调中值/阈值路径。该结果明确排除，没有部署、没有计入节省量。修正为提前声明的模块级网线后，`snapshot_final` 恢复完整路径；最终交付使用配套最终固件的 `release_snapshot`。

证据目录：`results/xlr_control_20261007/`。原生 build 使用 IMAGE_DEBUG=2、SAPPHIRE_ENABLE=1、RAW_TO_POOL=1、ANALYSIS_DMA_ENABLE=1、DISPLAY_LATENCY_PROBE=0、seed=1。没有启动 GitHub 硬件 Runner。
