# 识别困难与暗部彩噪修正 2026-09-19

## 已确认的识别问题
板上连续8个样本flags=9、valid0，background61，包围框空。原代码在四角任一像素跨度超过48时关闭整帧前景统计，少量噪点即可触发。
修正为四个16×16区域均值的跨度；取样区不参与前景包围框，避免一个角区异常点把框拉大。
中央ROI从1280×720缩小为640×480，坐标x640..1279/y300..779；灰度差阈值48降低为32。
增补“角区单个黑点”和“背景缓慢明暗梯度”的回归，旧规则前者失效，新规则17组用例通过。
这是单目标几何分类的改进，不是完整连通域/任意背景识别。

## 暗部色噪处理
本轮前ISP/曝光/白平衡/色调曲线未改。原rgb_shadow_denoise只作用于RGB均<=32且左右端点差<=4的邻域，覆盖范围窄。
新实现以Y=(R+2G+B)/4判断暗部和平坦亮度邻域，对R-G、B-G两路色差取横向三点中值，再用中心Y重建RGB。
保持原来一像素延迟和de/hs/vs对齐；亮区、明显亮度边界、行首精确旁路，稳定暗色也精确旁路。
不抬高黑位、不改变曝光、不过滤亮度；整型重建有舍入，饱和裁剪时亮度亦可能变化。暗部细小纯色纹理可能受色差滤波影响，应与实物对照。
37组邻域+行首测试通过，覆盖等亮度紫/绿噪声、中性黑、稳定暗色、亮处颜色及亮度细节。
尚未取得本轮前后原始帧，因此“用户看到的彩噪来源”和“肉眼改善幅度”仍待显示对照，未将算法测试等同于画质验收。
