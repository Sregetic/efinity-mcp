# M7：自动多目标轨迹、框内方向与单目标跟随

## 不居中，也能看全部目标的连续轨迹和方向

1. KEY1打开菜单，智能→模型选M7几何，推理模式选自动。
2. 目标→目标轨迹开启：自动记录M7识别到的最多4个目标，无需进入一键居中、无需选中、无需开启持续跟随。
3. 目标→运动提示开启：各识别框右上角显示该目标的左/右/上/下箭头，静止显示小方点；第一次观测尚无方向时不画箭头。

两个显示开关独立。在彩色、灰度、Sobel/Canny边缘和叠加模式均可使用。轨迹只取实际检测中心，不用全画面运动最强方向代替各目标运动，也不积分方向响应产生位置。原全局运动提示保留；逐目标箭头使用各目标自身的实测位移。

## 轨迹保存最近3秒的真实位置

目标按类别、源图位置和大小进行唯一双向关联，不依赖列表行号。列表重排不改变身份；同类交叉/关联歧义建立新身份，不将旧轨迹接到猜测目标上。短暂漏检不补点，唯一关联恢复可继续同一身份；超过3秒的历史自动消失。

每个目标最多12个显示采样点，相邻采样至少250ms，四目标合计不超过48个真实观测点；同一身份相邻且中间没有漏检的观测连接为连续折线，按小于1秒、1–2秒、2–3秒三档变淡。时间来自该Canny输入源帧的实际捕获时刻，不用分类完成时刻替代；同一源帧不重复追加，不跨漏检或关联歧义连线；线段只是实测点之间的绘制，不增加观测计数。

存储坐标统一为裁剪前1920×1080全景源图。检测时用当次源帧的ROI逆变换，显示时用当前已生效ROI正变换；视窗平移不会制造物体位移。当前视窗外的点不显示，回全景后可看到仍在3秒内的历史。

全目标位置/方向随实际M7类别完成更新，并不是4套15Hz局部跟踪器。字母分类原有复杂背景耗时仍在，不能用HDMI刷新率或单目标跟随频率代表全目标轨迹频率。

2026-11-02等价算术提速已临时加载：同输入总后端减少23%–34%，当前室内背景完整类别约0.88Hz；52类、阈值和轨迹关联不变。证据和Flash状态见[提速报告](../results/m7_speed_20261102/REPORT.md)，不能将此频率解读为选中目标的局部位置更新率。

## 一键居中和持续跟随仍单独使用

- 一键居中：进入实时全景列表，KEY2/KEY3选目标、KEY0确认，执行一次居中；KEY1返回。
- 持续跟随：先开启该开关，再从同一列表确认目标，以初始倍率平移ROI跟随这一个目标；重新进入列表可换目标。
- 关闭持续跟随不自动移动窗口；全目标轨迹和各框方向仍由各自开关控制。恢复全幅关闭自动跟随，不关闭目标轨迹。

选中目标的位置任务仍复用原RAW帧池lease、局部Sobel和边缘外观关联，与完整字母判定分开。短暂停更进入HOLD，超过1.5秒且至少3次实测失配或源完全停更3秒才丢失；关联歧义停止，不自动换物体。CONFIG仍保留，KEY1只负责菜单/返回。

## 制品和验证

2026-11-02实现与报告在`results/multi_target_motion_20261102/`。原SDI Flash制品仍在`results/hdmi_finalize_20261101/flash/`；新版本是否已临时加载、是否写Flash，以本轮REPORT.md和acceptance.json为准。

点轨迹版整机P&R53979/60800XLR、239/256RAM、60/160DSP，WNS+.101/WHS+.026ns；最终连续线整机56540XLR/240RAM/63DSP，WNS+.227/WHS+.026；已临时SRAM/DDR加载，Flash未改。4个身份/历史结构768B；无新增视频缓存、DDR帧槽、FOMO arena或模型。M0–M6 Canny/Sobel和M7字母数值规则保持，人脸仍关闭，独立FOMO不改。

自动关联和服务验证：`scripts/test_target_motion.py`；框内方向/48点实际1080p栅格及连续线栅格：`sim/vision/tb_target_motion_overlay.sv`、`sim/vision/tb_target_line_overlay.sv`。原单目标跟随验证继续使用`test_target_follow.py --no-face`。MTK1扩展能力位于M7 APB0xac，0xa8返回接受边缘的源捕获毫秒；连续线能力位于0xbc（MLN1），轨迹提交0x9c的bit1选择连续线格式；原点格式和TRK1/标签/控制ABI保持。新完整固件要求MTK1/MLN1配套位流，不能单独加载到旧Flash位流上。

连续线复用原48个显示记录，每条线以两个1/4显示分辨率端点及三档亮度编码，占用的轨迹RAM不扩容；只有行交点计算使用一张小倒数ROM。CPU约每33ms按真实时间刷新淡出/过期，原子VS换包。ROI裁剪仅裁切绘制线段，历史观测仍保留原全景源坐标和时间。
