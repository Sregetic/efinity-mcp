# A6 简易形状识别：移植与验收

本轮目标：原赛题高级功能A6的圆形、矩形等简易识别；不引入神经网络、RISC-V或多目标检测承诺。

## 操作
- M7默认显示彩色原图、虚线识别区域、目标框与SHAPE类别文字。
- 识别区域：HDMI坐标x=640..1279、y=300..779。完整目标放在虚线区域内。
- 在均匀的白纸/浅色背景前放一个实心深色圆或矩形；也支持深背景上的浅色目标。
- 白纸应覆盖识别区域的四角。尽量避开阴影、反光、文字纹理，目标最小16×16像素，面积至少256像素。
- 绿色框CIRCLE；蓝色框RECT；黄色框OTHER；NONE表示无有效候选或输入条件不满足。
- JTAG：`scripts/vision_control.py --mode 7 --shape 1 --shape-threshold 32`。
- 关闭识别叠加并恢复旧M7左右原图/灰度对比：`--mode 7 --shape 0`。
- 形状灰度差阈值独立于Sobel/Canny阈值；`--shape-threshold`范围1..255，默认32。
- 原有物理模式切换按钮可切到M7；其他按键含义不变。

## 实现与边界
附件的单目标面积/包围框分类方法移植为独立vision_shape_classifier.sv。
四个16×16角区合计1024像素求背景均值；使用上一显示帧背景，不将一个像素视作可靠背景。
收集面积、包围框、触边标志及每行前景段数。矩形不再限制近正方形；圆形增加长宽比及填充率约束。
空白、过小、触边、四角背景跨度过大、过多多段前景行被标记为无效。
分类结果属于上一显示帧，帧边界后经过两级计算发布；运动目标的框会有一显示帧的滞后。
单目标、实心、均匀背景；矩形按接近水平/垂直摆放验收。没有完整连通域/轮廓拟合，多个上下分离目标、部分遮挡、复杂背景、旋转矩形仍可能误判，OTHER不是任意物体语义识别。
灰度差取绝对值，支持明暗反转；相同灰度的不同颜色目标不适用此分割方法。
分类器无整帧缓存，视频每拍持续处理，不对前端施加背压。

## 接口
JTAG opcode22：识别叠加开关；opcode23：灰度差阈值；在帧边界提交。
诊断page10标识260919A6：高32位保留highlight_pixels，低64位为：
63 enable，62 valid，61:60 class，59:52 background，51:48 reject_flags，
47:36 x0，35:24 y0，23:12 x1，11:0 y1。
reject_flags位0过小/空白，位1触边，位2多段前景行，位3背景不可用/不均匀。
状态为帧间保持的观察值，诊断读取应使用多个样本，忽略恰好落在发布边界的样本。

## 实物验收
1. 白纸覆盖虚线区域、无目标：NONE，无虚假目标框。
2. 实心圆：CIRCLE，框围住目标；缓慢移动并保持在区域内。
3. 横矩形、竖矩形：RECT，不只测正方形。
4. 三角形/不规则块：OTHER，记录误判。
5. 目标移出/遮挡识别区域边界：NONE；重新放入可恢复。
6. 检查M0原图、M5/M6 Canny、M7旧对比、冻结/回放没有回退。
保留实物照片及误判情况；在这些验收完成前，A6标为已实现待实物验收，而不是全部完成。
