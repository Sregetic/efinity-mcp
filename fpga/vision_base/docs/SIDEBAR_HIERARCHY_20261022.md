## 按键顺序

1. 长按KEY0，只打开“图像 / 视图 / 目标 / 智能”一级分类。
2. KEY2/KEY3上下选分类，短按KEY0确认后才展开二级菜单。
3. KEY2/KEY3选二级项目。选中“中值滤波”时，短按KEY0直接开关，留在当前行；其余项目短按KEY0进入编辑或动作确认。
4. “显示模式”进入后直接展开八模式列表并处于编辑状态。KEY2向上、KEY3向下循环选择，选到哪个就预览哪个；短按KEY0保留当前模式、收起第三列，返回二级列表。长按KEY0取消预览并恢复进入前的模式。
5. “边缘阈值”只需短按KEY0进入编辑一次，随后KEY2/KEY3连续调节并立即应用，无需每次确认。短按KEY0或长按KEY0退出编辑，均保留已应用的阈值。步长仍为16，Sobel/Canny范围16–2047，几何识别范围1–255。
6. 其余项目仍使用草稿：KEY2/KEY3调节，短按KEY0确认生效，长按KEY0取消。未编辑时长按KEY0逐级返回：二级列表→一级分类→关闭。

KEY2/KEY3的原长按冻结/历史功能、KEY1复位保持。关闭菜单后，原模式切换、阈值和历史索引短按规则继续工作。居中与恢复全幅及原帧持有/提交机制见上一轮说明；新位置为“目标”组，功能保持。居中状态显示就绪、等待、完成、无目标、正忙、已过期、出错。
