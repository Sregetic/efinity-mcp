# 中文侧栏：显示与识别模型独立选择

当前SDI工程使用HQ12 HDMI输入，原摄像头工程已备份。模型保留FOMO和M7几何，默认M7、推理关闭；实际固化状态与配套制品以[项目总状态](PROJECT_MASTER_STATUS.md)最新摘要为准。

## 视图上下调节立即生效

进入“视图”中的图像缩放、平移、输出尺寸或位置，按一次KEY0进入编辑后，KEY2/KEY3每次调节都直接更新画面，不需要逐步确认。KEY0“完成”结束编辑；KEY1“返回”也保留当前结果。连续按键通过原ROI事务排队，只在帧边界提交，不覆盖正在使用的构图。

## 在边缘画面中看M7结果

1. 短按KEY1打开菜单，KEY2/KEY3选择“智能”，短按KEY0展开。
2. 进入“模型”，KEY2/KEY3选择“M7几何”，短按KEY0确认。
3. 将“推理模式”设为“自动”。若选择“固定单帧”，每次在“立即推理”确认后运行一次；“关闭”停止识别，不再暗中调用旧定位。
4. 返回“图像→显示模式”，选择“SOBEL边缘”“CANNY边缘”或对应叠加模式。上下选择实时预览，KEY0保留选择并收起模式列，短按KEY1取消预览。

M7分析统一读取现有Canny接受位图；Sobel只改变显示背景，不另加识别方法。要调整M7的主边缘阈值，先选择Canny边缘或叠加显示，再到“图像→边缘阈值”调节。Sobel和Canny各自保存阈值，范围16–2047、步长16；旧灰度几何1–255阈值已退出。

## 全景选择目标，再居中

在M7中选中“目标→一键居中”，短按KEY0直接展开第三列。恢复全景后持续实时预览；圆/矩形/字母完成后更新1–4行选项（人脸暂时停用），不再冻结屏幕或等待同帧完整列表。当前没有检测结果时显示“等待”或“无目标”，之后仍可自动出现新目标。

KEY2/KEY3选择，框和标签变为洋红色。更新时尽量保留相同类别、位置重叠的所选目标，而非固定行号；目标消失或关联不唯一时清除选中，按上下重新选择。此时没有选中边框，KEY0不提交其他对象的坐标。确认后收起第三列，一次性等比居中；短按KEY1取消并留在全景。

再次进入会恢复全景并重新实时选择。选择期间临时用F0预览，确认/取消恢复原F0/F1；固定单帧策略在列表打开期间临时连续工作，退出后恢复。关闭“持续跟随”时只执行一次居中；开启后按选中目标平移ROI。倍率上限和FOMO原操作保持，详见[M7跟随](M7_FOLLOW_TRAJECTORY.md)。

## 按键与布局

短按KEY1打开一级分类；KEY2/KEY3上下选择，短按KEY0进入/确认。KEY1在编辑时取消或退出，在二级返回一级，在一级关闭菜单；连续阈值和六个视图值退出都保留实际调节结果。菜单关闭时KEY0短按仍快速切换显示模式；长按KEY0不再发返回或确认。KEY1不复位整机，CONFIG保留重新配置；KEY2/KEY3原长按冻结/历史保持。居中状态仍包括就绪、等待、完成、无目标、正忙、已过期、出错。

一级宽144像素，二级宽160像素，总宽304；模式/目标选择第三列再加160，总宽464。每行64像素，从y=128开始，保留顶部状态栏。模式列含七种显示及标题/提示，高576像素；目标选择列按1–4项动态收缩，最多384像素；最长二级视图组高576像素。四分类、19项。

菜单文本由scripts/generate_sidebar_chinese.py生成，当前76条文本使用126个汉字，16×16点阵；ASCII沿用5×7二倍显示，并补齐目标列表所需a–z与斜线。使用紧凑字形编号，无UTF-8运行时解析、完整字体加载或UI帧缓存，原同步读取一拍保持。

## 配套接口与证据

控制ABI为0x26103106，M7为0x26103173，标签能力M7L1仍为0x4d374c31，UI诊断page32为0x26103144，并提供KEY1输入状态key1_n。目标选择包含结果bank标记，防止新框与旧行号混配；M7状态bit5可读当前发布bank，CPU替换后保持标签对应。显示/模型/定位使能仍经现有VS边界整包提交；退役灰度阈值的控制位复用，不新增CDC框架。CON4结构原shape_threshold槽保留地址但置0，不参与判定；旧CLI灰度阈值选项已移除。旧应用与新位流不能混用。

FOMO/M7切换、退役模型0拒绝、一次居中和M7跟随服务回归保持通过。当前SDI固化版即时视图已通过RV32/板上事件与实际显示检查，完整资源和现场待验项见[SDI固化报告](../results/hdmi_finalize_20261101/REPORT.md)。候选/历史版本的制品不能代替当前正式release。
