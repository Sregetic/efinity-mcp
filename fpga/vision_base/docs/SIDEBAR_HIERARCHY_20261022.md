## 按键顺序

1. 长按KEY0，只打开“图像 / 视图 / 目标 / 智能”一级分类。
2. KEY2/KEY3上下选分类，短按KEY0确认后才展开二级菜单。
3. KEY2/KEY3选二级项目，短按KEY0进入编辑或动作确认。
4. 编辑时KEY2/KEY3调节，“显示模式”等项目直接显示草稿文字名称；再次短按KEY0提交，返回二级列表。页脚相应显示“K0进入 / K0确认 / 长按返回 / 长按取消”。
5. 长按KEY0逐级返回：取消编辑→二级列表→一级分类→关闭。取消时实际参数保持原值。

KEY2/KEY3的原长按冻结/历史功能、KEY1复位保持。关闭菜单后，原模式切换、阈值和历史索引短按规则继续工作。居中与恢复全幅及原帧持有/提交机制见上一轮说明；新位置为“目标”组，功能保持。居中状态显示就绪、等待、完成、无目标、正忙、已过期、出错。
