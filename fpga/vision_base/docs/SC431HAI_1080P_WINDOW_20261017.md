# SC431HAI 中心1080p窗口试验

本分支让现有SC431HAI在传感器内部输出1920×1080窗口，复用`camera_native_1080`旁路FPGA的`bayer_fov_reduce`。SC431HAI四lane/RAW10、原PLL/HTS/VTS、约30fps、曝光单位、镜像和白平衡保持；SC2210原生输入复用同一模块。默认无profile构建仍是完整1440p视场，Flash保持原发布。

## 窗口与取景

|寄存器|设置|含义|
|---|---|---|
|3208/3209|0780|输出1920列|
|320a/320b|0438|输出1080行|
|3210/3211|0144|传感器输出列起点324|
|3212/3213|00b8|传感器输出行起点184|

原输出起点为4/4，新窗口相对原2560×1440有效区的偏移是320/180；两个偏移均为偶数，保持原Bayer相位。水平/垂直保留原采样范围的75%，有效区像素面积为56.25%，不是全视场缩放或binning；同一物体在1080p画面中约放大4/3。外围场景不再进入后端ROI/历史帧。

初始化表由现有166条SC431HAI启动写入生成，仅七个窗口寄存器字节取值变化。传感器读取区域、时钟、模拟/数字增益、曝光和最后开流顺序保持。profile的表身份校验沿用现有构建契约。

## 实施和构建

- `F:/Project/fpga/vision_base/board/ti60f225_v4/sensors/sc431hai_1080p30_center_4lane.json`
- `F:/Project/fpga/vision_base/board/ti60f225_v4/sensors/sc431hai_1080p30_center_4lane.mem`
- `VISION_SENSOR_NATIVE_1080`只选择输入归一化模块；`VISION_SENSOR_SC2210`继续选择传感器复位、曝光和色彩参数，两者职责分开。
- 原生模式在现有512深RAW FIFO内预填充完整一行480字，再连续输出960个双像素拍。实测CSI字节时钟约40MHz，RAW10四像素字有效速率约32M/s，低于ISP的74.25M字/s消费速率；原半行预填充会在一行结束前读空。FOV模式仍用原半行预填充，不增加RAM。

```powershell
Set-Location F:/Project/fpga/vision_base
& ./scripts/synthesize.ps1 -Top board -Flow compile -Sensor sc431hai `
  -SensorProfile ./board/ti60f225_v4/sensors/sc431hai_1080p30_center_4lane.json `
  -TimeoutSeconds 1800
```

构建通过后，沿用`program_vision_sram.ps1`的源文件/制品/最终时序与引脚检查，以当前枚举的USB URL写入SRAM。程序和权重仍由现有ROM从Flash加载，不修改Flash。KEY1复位继续使用当前SRAM内的窗口表；断电或重新配置会加载原Flash中的1440p版本。
