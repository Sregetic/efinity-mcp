# M7 face category

Pixel-intensity-comparison cascade from pico (MIT), not an identity model.
Source: https://github.com/nenadmarkus/pico/blob/346881039e5d1f5abe64733a49886bdfd5ab2d51/rnt/cascades/facefinder
Paper: https://arxiv.org/abs/1305.4537

This model belongs only to M7 geometry. Existing TinyML/FOMO/connectome models are unchanged.
The 239632-byte cascade is stored in CPU DDR, not FPGA block RAM.
