# 2026-09-16：按Gamma旁路对照修复颜色变淡

## 依据
用户在白平衡校正后仍反馈颜色很淡。只旁路Gamma后，用户明确反馈“明显好很多，但暗的地方很暗”。这是本次修改的直接依据，不再把中性白纸读数接近视为完整色彩验收。

旁路对照的中央区域测量：旧逐通道Gamma约R126.69/G102.16/B101.50；线性旁路约R54.84/G34.36/B33.82。该场景中通道相对差异从线性约38.3%压到19.9%。这不是完整颜色校准指标，但与用户的对照观察一致。

## 改动
新增rgb_chroma_tone.sv：取max(R,G,B)查表获得公共增益，三通道乘同一个增益。明暗包络采用原显示Gamma曲线，近黑最大公共增益限制4倍，纯黑仍为0。这样提亮时保留线性RGB比例（仅有整数舍入误差），不再分别拉升每个通道。

例：线性(55,34,34)，旧逐通道提亮约(127,102,102)，新公共增益输出(127,78,78)。这展示数值比例差别，不是承诺实物颜色已经完成标定。

统一三拍像素及DE/HS/VS延迟：模式0线性旁路；模式1原逐通道Gamma；模式2新公共增益提亮。默认模式2，可通过vision_control.py的--tone（兼容--gamma）实时切换，场消隐生效。

曝光1776半行、物理白平衡增益R162/G161/B256、R/B校正、视场、HDMI时序和Canny算法均保持原样。

## 验证
800组RTL样本通过，覆盖独立RGB、纯色、灰阶、纯黑、消隐、同步和线性旁路对齐。256级明暗包络检查：单调，黑0、白255，公共增益不超过4倍。

最新布局布线、SRAM下载和同一冻结帧三模式对照记录将在本目录追加。真实场景颜色与暗部效果仍需用户确认。
