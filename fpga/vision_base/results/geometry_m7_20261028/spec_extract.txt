核心任务拆解——基础要求
1. 摄像头驱动与图像采集
• 分辨率要求：640×480或以上
• 采集图像数据并存入行缓存（FIFO或Block RAM），为后续处理做准备
• 要求图像采集稳定，无丢帧、无错位
2. 彩色图像转灰度处理
• 要求使用FPGA内部的DSP块或移位加法实现乘法运算，避免使用除法器
• 灰度转换是边缘检测的前置步骤
3. Sobel边缘检测算法实现
• 实现3×3 Sobel算子，计算水平方向梯度Gx和垂直方向梯度Gy
• Sobel算子卷积核：
➢ Gx（x方向梯度）：[-1, 0, +1; -2, 0, +2; -1, 0, +1]
➢ Gy（y方向梯度）：[-1, -2, -1; 0, 0, 0; +1, +2, +1]
• 梯度幅值近似计算：G = |Gx| + |Gy|（避免开方运算，节省硬件资源）
• 通过阈值比较输出二值化边缘图像（阈值可参数化配置）
• 需设计行缓存模块（Line Buffer）缓存2行数据，实现3×3窗口的滑动处理
基础目标：本部分考察参赛者对FPGA外设驱动、数据流控制、基础图像处理算法的掌握能力。
4. HDMI显示驱动
• 生成标准HDMI时序（最低要求：640×480@60Hz）
• 实现分屏显示：屏幕左侧/上半部分显示原始灰度图像，右侧/
下半部分显示边缘检测结果
• 或实现画中画叠加显示
• 显示稳定，无闪烁、无撕裂
5. 基础验证
• 提交完整RTL源码（Verilog/VHDL）和约束文件
• 提供演示视频：摄像头对着简单几何图形（如黑白棋盘格、印
有数字的纸张、人脸轮廓），展示边缘检测效果

核心任务拆解——高阶挑战
进阶目标：为有余力的队伍提供拓展空间，完成度越高，得分越高。算法复杂度和视频帧频也是考核维度。
1. 中值滤波去噪
• 在灰度化之后、边缘检测之前插入3×3中值滤波模块
• 实现9个像素值的排序，取中位数作为输出
• 有效抑制椒盐噪声，提升边缘检测质量
• 需合理设计排序网络（可采用并行比较网络，避免串行排序）
2. 实时阈值调节
• 通过板载按键或拨码开关，实时调整Sobel边缘检测的阈值
• 效果：按“+”键提高阈值（边缘减少），按“-”键降低阈值（边缘增多）
• 需设计按键消抖模块与阈值寄存器
• 该功能在现场演示时能直观展示阈值对边缘检测结果的影响
3. 帧缓存与DDR控制
• 将一帧完整图像写入外部DDR存储器，实现“采集-存储-读取-处理”分离
• 可实现回放、帧冻结、多帧对比等功能
4. Canny边缘检测（算法升级）
• 实现更高级的Canny边缘检测算法（高斯滤波→梯度幅值和方向计算→非
极大值抑制→双阈值分类 → 滞后边缘连接）
• Canny相比Sobel能获得更精确、更连续的单像素边缘
• 但实现复杂度显著提升，需要更精细的流水线设计
5. 边缘叠加彩色输出
• 将检测到的边缘以彩色形式（如红色边缘线）叠加到原始彩色图像上输出
• 视觉效果更直观，适合现场展示
• 需要处理RGB三个通道的叠加逻辑
6. 简易目标识别（创意拓展）
• 在边缘检测的基础上，识别画面中的特定形状（如圆形、矩形）
• 可采用特征匹配法：在边缘图像中检测轮廓，计算几何特征
• 将识别结果显示在屏幕上（如“检测到圆形”）

为什么滞后连接单独作为帧级任务
与强边缘相连的弱边缘可能形成任意长度路径。单次局部 3×3 检查或固定次数的邻域传播通常只构成近似。首版
