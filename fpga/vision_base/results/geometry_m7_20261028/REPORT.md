# M7 边缘几何、多目标与人脸检测修订

## 已固化Flash，应用自主加载与自动验收通过

人脸归入 **M7 几何识别**，与圆、矩形一起输出。独立 AI 模式的模型和推理算法未改；M0–M6 行为保持。最终配置及完整应用/原权重已固化 **Flash**；配置onchipx1校验、应用包实际回读通过。重配同一最终SRAM后，ROM从Flash自主加载447344B应用和4400B权重，全部实际DDR字节再次核对一致，期间没有USER1程序下载。

当前板子为实时 **M7 / MED1 / F0 / Sobel96 / Canny96 / 几何开启**，全幅、ROI关闭，一级“图像”菜单打开。CPU运行，外部Canny持有和测试冻结均已释放。现场目前只有瓷砖背景；实物正样本尚未验收。

## 按赛题边缘路径判几何，人脸同列

依据2026赛题指南更正版第26页高阶6：在边缘图像中检测轮廓、计算几何特征、显示圆/矩形结果。原文及来源路径保存在 `spec_extract.txt`；人脸、多目标是用户追加要求。

M7复用生产Canny接受的480×270二值平面，提取闭合轮廓，以多边形/圆度判圆和矩形，映射到1920×1080全屏视图；原处理链无效边界保持。旋转矩形、独立和尺寸不同的嵌套对象均有测试。细笔画内外轮廓去重，最多显示四个较大结果，`N4+`表示仍有其它目标。接触后合为复杂轮廓的物体不保证拆分。

人脸采用Pico传统像素比较级联，并要求同源Canny支持；不是将椭圆当人脸，也不做身份辨认。239632B固定模型存在CPU DDR，没有新增FPGA神经网络或整帧片上缓存。仅检测未旋转窗口；上游候选缓冲上限1024。来源与MIT许可见 `models/geometry_face/README.md`、`firmware/vision/pico/` 和 `FACE_SOURCE.md`。

圆框绿色、矩形框蓝色、人脸框黄色；HUD显示主目标及 `N/C/R/F` 数量。人脸优先替换同一对象的近似几何框，之后按面积排序。M7本地类别3为FACE，原I3接口的类别3仍为OTHER，不改AI类别表。

M7边缘阈值默认96，范围16..255，KEY2/KEY3每次16；进入编辑后连续生效。模式第三列即时预览/KEY0收起、中值KEY0直接开关保持。公开状态及RGB24快照在M7均报告实际边缘请求值，不再错误暴露旧灰度32；其它模式原参数语义保持。

## 更新速度与现场剩余项
