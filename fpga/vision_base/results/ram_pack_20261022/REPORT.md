# 六项RAM打包优化实施与离线验收

日期：2026-10-22。用户要求实施前轮审计的优化，保持图像效果、既有功能及图像回读。本轮已修改生产源码并完成整机原生编译、接口、P&R和位流生成；没有访问硬件，没有写入SRAM或Flash。

## 1. 实际结果

对比基线为 `results/motion_sidebar_20261022/` 的完整中文菜单、对称居中、运动提示版，不是历史精简构建。

|资源|优化前|优化后|变化|当前空余|
|---|---:|---:|---:|---:|
|RAM|249/256|239/256|**释放10块**|17块|
|XLR|59878/60800|60510/60800|增加632|290，使用率99.52%|
|DSP|63/160|63/160|0|97|

最终WNS **+0.112ns**，WHS **+0.028ns**；Unassigned Core Pins为0，原有14项Missing Interface Pins的名称/方向集合保持。route XML还包含初始布线的负裕量，验收读取的是 **Timing (Final)**，不混用初始或中间结果。

本轮目标是回收RAM，并未同时减少XLR。后续新增硬件逻辑前，优先继续回收XLR；17块空余RAM不代表有足够逻辑加入大型加速核。

## 3. 图像一致性与功能检查

### 实际生产RTL，不仅是隔离算式

- `sim/vision/tb_canny_storage.sv`：当前生产模块的8192种邻域/子像素组合与旧覆盖率表一致；65536种有符号拟合输入联合组合与旧ROM逐拍一致。该检查已接入标准 `scripts/verify_vision_features.ps1`。
- 修改前Canny RTL冻结副本与新RTL同时接收同一480×270位图、真实1920×1080光栅及行消隐。两帧 **4147200个有效像素、4773472个完整周期** 的取数地址、二值像素、覆盖率和统计均一致；含斜线、拐角、圆弧、稀疏随机点及密集块。结果见canny_ab.run.log。
- 既有Canny几何测试：138240个光栅像素、6528个拟合像素、8256种像素面积情况通过，含正负浅/陡斜率和下一空帧。原raster测试也通过。
- 当前生产OSD：全部121个中文字模及128个ASCII码，共55552个字模像素检查通过；4组/17项菜单、八模式名称、状态、单位及144/304宽度保持。
- 新cache标签：10000次完整23bit随机读写，含同址读写旧值及读使能保持；原字节掩码、22bit旧配置、元数据和UART检查保持通过。
- 三个相机profile：253/251/166条启动序列、profile校验、reset极性/延时/饱和、RAW/debayer/native1080流检查通过；17种前缀输入在实际pre-build入口被拒绝。当前默认sensor header保持。
- 运动核心62帧、864个采样网格、policy、57个读出检查通过；生产显示链24个光栅/八模式共463059个RGB/同步周期一致，冻结/历史/关闭复位策略通过。
- 中文运动提示6种状态及HOLD、RV32I第16项和4007264个菜单外像素/字符检查通过。
- RGB24行快照、边缘叠加、强度、融合显示的定向回归通过。图像快照仍 **5块RAM、24bit、1920全宽**。

原图ISP、Gamma、色调、输入分辨率、RAW10接收、帧池、ROI渲染、DDR仲裁及AI模型/固件不是本轮修改项。原生输入清单相对基线只有 **5个RTL文件和2个新字典文件** 改变，见native_input_changes.json；RAM逐层own数量之和为239，未重复累计父子层级。
