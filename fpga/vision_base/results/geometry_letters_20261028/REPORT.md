# M7印刷字母与逐框标注：离线候选

## 结果与使用

M7新增A–Z、a–z共52类，沿用Canny接受边缘→轮廓几何判定。框上显示实际字母或圆形/矩形/人脸；字母青色，顶部摘要LETTER及L计数。最多4框，超过显示N4+。菜单入口、独立AI、Canny检测/追踪/连续显示不变。

使用正向、分离、同字号的清晰印刷体。建议单字在1080p画面中高约200像素以上；本次受测实际边缘框高180–496像素。某些I/l同形时明确显示I/l。详细用法与ABI见docs/M7_PRINTED_LETTERS.md。

## 自动验证

79个完整输入场景经过生产RTL Canny，三种字体、两种未参与参考生成的字号，共312个字母：306明确、6保留I/l；52类均有明确样例。框位置、最多4框及溢出提示均通过。主机ASan/UBSan及实际RV32I执行一致，包含所有候选身份和最终显示框。

原26组圆/矩形/人脸、私人快照覆写、源帧/上下文、慢人脸期间几何推进、VBlank快照拒绝不清旧结果、原阈值/按键回归通过。M7标签和完整RGB各2073600像素检查通过；菜单69段文字/121汉字及55552字体像素、侧栏5834589区域外RGB/同步检查通过。最终Latin14px/CJK15px逐字形边界检查及实际字形预览完成，保留j/g/p/q/y下伸部与V/Y左边缘。

识别工作在CPU外部DDR中；人脸保持独立快照/完成路径，几何和字母任务分段执行。实际摄像头识别率、刷新速度和运动滞后尚未测量。
