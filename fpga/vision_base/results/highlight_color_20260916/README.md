# 2026-09-16：饱和高光偏蓝保护

## 证据与范围
用户反馈新公共增益提亮后，窗外亮光变蓝。RAW稀疏读回240个2×2块，11块至少一个样本>=250；两绿色位置最大255，红色位置最大255，而蓝色位置最大208。样本例（B/G/G/R）为208/255/255/255。

扣黑电平16并施加当前物理R162/G161/B256增益后，该均匀样本约为R151/G150/B192。旧公共增益提亮保留了这个因通道饱和而失真的比例，模型输出约177/176/225，表现为偏蓝。

这与普通蓝色物体不同：蓝物的红/绿RAW通常没有同时变亮。普通中暗部不应跟随高光一起降低蓝色或去色。

## 实现
保留线性旁路（tone0）、旧逐通道Gamma（tone1）、旧公共增益（tone2），新增tone3并设为默认。

在现有黑电平与实际白平衡增益下，把RAW近饱和门限映射到处理后的三通道。仅当至少一个通道接近传感器饱和、且三个通道都具有较高输入亮度时，分8级向当前亮度峰值的中性色过渡。

近饱和窗口起点对应RAW约223；全通道较亮门限从RAW约128开始过渡。阈值随白平衡增益更新；不是直接把显示值很蓝的像素全部去色。已经丢失的高光细节不作恢复承诺，目标是避免把失真的高光呈现成蓝色。

所有显示分支统一为四拍RGB/DE/HS/VS延迟。新增诊断页10读取高光保护命中像素数。曝光1776半行、白平衡数值、视场、Canny、DDR功能保持原样。

## 验证
800组RTL样本通过：含实际窗外样本、明亮蓝物、普通颜色、消隐、同步、旧公共增益和线性旁路。实际窗外均匀样本模型由177/176/225变为225/225/225；纯蓝类样本保持旧公共增益结果。

最终时序、下载、同帧tone2/tone3和板上命中计数在本目录追加。实际窗外观感与其他高亮彩色物体仍由用户观察验收。
