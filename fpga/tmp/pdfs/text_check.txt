04 / MIPI 硬件与像素格式契约
MIPI 只是接口族名称。首版按 CSI-2 over D-PHY 建立接入契约；连接器外形相同不代表引脚、电压或 lane 映
射相同。官方 RX IP 支持多种 RAW/RGB/YUV 格式，具体输出取决于所选 IP 与传感器配置。[R4]
需要确认
冻结内容
影响

传感器型号、模组版本、镜头与视场
寄存器表、成像质量、最小可见缺陷
电气与连接
FPC 方向、pinout、供电、I/O 电平、复位、MCLK
实物连接与供电时序
链路参数
数据 lane 数、lane 顺序/极性、每 lane 速率、时钟模式
D-PHY 与 CSI-2 IP 配置
数据描述
RAW 位深/Bayer 排列或 YUV/RGB；VC、DT、有效尺寸
解包、行字节数和 ISP 路径
工作模式
实际支持的尺寸/FPS、曝光、增益、裁剪/binning
带宽、运动模糊与训练分布
工具基线
板卡工程、Efinity、IP 版本和约束文件
编译一致性与已知问题复现
必须补上的 RAW / ISP 分支
相机输出 RGB/YUV 按通道顺序、量化范围和打包方式归一。YUV 可提取 Y 供算法使用，彩色显示还需对应色
彩转换。
相机输出 Bayer RAW 先按 RAW10/RAW12 等格式解包，核对黑电平、有效位深和 Bayer 排列。彩色叠加要求
保留可用彩色图，首版可使用经过验证的轻量去马赛克及定点颜色处理。
算法输入契约 基础边缘算法暂定 Gray8；显示暂定 RGB565 或 RGB888；训练与板端必须采用同一裁剪、缩放
和归一化流程。
当前决策
MIPI 为设计基线，SC431HAI 等资料中型号仅作为兼容性核查候选。摄像头准确型号未定前，lane 数、RAW 格式、寄存器
地址和最高帧率保持待确认状态。

05 / MIPI 接入与跨时钟域设计
按可观测结果逐步调通
步骤
工作内容
进入下一步的条件
M1 电气/时钟
核对接口、电源顺序、复位和参考时钟
实测供电与时钟符合模组要求
M2 I²C 配置
读取芯片 ID；写入选定模式；核查关键寄存器
ID 与模组一致，配置读回合理
M3 链路接收
启用 D-PHY/CSI-2；优先传感器测试图
IP 锁定/状态有效，包错误计数稳定
M4 图像解包
VC/DT 过滤；像素位序、行长度和帧尺寸检查
色条/灰阶与预期一致，无周期条纹
M5 显示直通
格式归一、帧缓存和 HDMI 输出
图像方向、颜色、尺寸和更新率正确
M6 算法接入
按灰度、中值、Sobel、Canny、AI 顺序集成
每步保留直通对照与计数证据
时钟域与数据流
独立时钟域 至少区分接收恢复/字节时钟、系统处理时钟、DDR 用户时钟及显示像素时钟。同标称频率也可能互
为异步。
像素跨域 用合适的异步 FIFO 或跨域视频缓冲连接；像素、SOF、EOL 和必要标记作为同一数据单元传输。核对 
IP 是否多像素/周期输出，再转换到内部格式。
真实输入约束 摄像头通常按固定节奏发送。下游背压需要足够缓冲；FIFO 溢出时记录并丢弃损坏帧，在新帧边
界重新对齐，测试中明确计为采集失败。
长期速率匹配 异步 FIFO 只吸收短时相位与突发差异。帧率差需通过已验证的相机模式、帧缓存策略和显示重复
解决；基础验收工作点要求采集无意外丢帧。
可观测寄存器
至少记录 frame_count、frame_size_error、fifo_overflow、display_underflow；ECC/CRC/SoT 等计数按所选 IP 暴露能
力接入。计数复位与采样窗口由软件统一管理。

06 / 灰度、中值与 Sobel 实现
像素流水线与边界
在支持背压的内部接口上，仅当 valid 与 ready 同时成立时推进像素状态；在固定速率接口上按有效像素使能推
进。消隐期间保持窗口计数逻辑一致。行首、帧首重新初始化必要的窗口状态。
模块
首版实现
正确性要点
灰度
Y = (77R + 150G + 29B + 128) >> 8
针对 8 位 RGB 的定点近似；和权重为 256；
舍入后输出 Gray8
3×3 窗口
两条行缓存 + 三行移位寄存器
宽度由工作模式冻结；相邻滤波级各自承担所
需行缓存
中值
九输入比较/选择网络，输出第 5 顺序统计量
行排序再列排序取中心不保证中位数；使用完
整网络
Sobel
Gx/Gy 分级求和，G = |Gx| + |Gy|
Gx/Gy 用至少 11 位有符号数；幅值用至少
11 位无符号数
阈值
边缘 = G 大于阈值；关系在软件参考中一致
先使用完整梯度范围比较，再转换为显示亮度
边界策略
首版固定边缘填零，输出仍保持原始尺寸
参考算法使用同一规则；卷积中心与原彩色图
对齐
流水线与性能描述
设计目标 完成流水线填充后，在选定内部数据率下持续接收有效像素。首版优先单像素/周期，IP 多像素输出通
过速率适配处理。
不使用虚假零延迟表述 两行缓存带来窗口形成等待，各级还存在寄存器延迟。分别记录输入到算法输出、输入到
显示的实际延迟。
复用策略 Sobel 与 Canny 的梯度模块可按互斥模式复用；若要求同帧同时比较，应通过缓存重放、时分调度或
资源评估后增加并行实例。
窄范围验证
使用斜线、棋盘格、脉冲点、椒盐噪声及随机窗口；灰度检查定点误差，中值与 Sobel 对照相同位宽和边界规则的参考实现。

07 / 完整 Canny 与几何分析
Canny 路径保留题目要求的五个阶段。高斯核、梯度度量、方向量化、NMS 相等值处理和边界规则都需要写入
实现规格，防止只比较最终画面而忽略算法差异。[R1][R8]
阶段
建议实现
关键验证

3×3 可分离定点高斯作为首版候选；复用梯度运算
与同核/同定点参考一致；噪声与细边缘权衡
方向与 NMS
用符号/比较方法量化到 4 个方向，再比较方向邻

边界
双阈值
生成强、弱、背景三类状态
约束低阈值小于高阈值；分类型状态可复核
滞后连接
首版候选：帧状态图 + 强边缘种子队列 + 8 邻域
遍历
弱边缘入队前立即标记，避免重复；队列按
最坏规模设计
几何提取
连通域/轮廓与面积、包围框、质心、周长等特征
圆/矩形判定对噪声、旋转和遮挡有明确范围
为什么滞后连接单独作为帧级任务
与强边缘相连的弱边缘可能形成任意长度路径。单次局部 3×3 检查或固定次数的邻域传播通常只构成近似。首版
通过帧状态与工作队列实现完整连通性；RTL 控制器执行邻域访问，RISC-V 负责启动、完成事件和状态管理。
每个候选像素最多入队一次，可将节点访问数量限制在有效像素数量级，但实际时延还受 DDR 随机访问、缓存
和仲裁影响。先验证完整性，再决定是否改进为行程编码/连通域标号；两条实现路线不同时铺开。
测量与应用输出
基础形状识别 先完成题目中的圆形和矩形；再扩展到选定工件的孔位、外轮廓与缺角。
尺寸标定 初期输出像素单位。只有经过镜头畸变、平面尺度及姿态条件标定后，才输出物理尺寸和误差范围。
Canny 验收边界
视频显示刷新率与完整 Canny 结果更新率分别报告。长弱边缘链、孤立弱边缘、对角连接、大连通区域都应进入针对性测试。

缓存所有权
建议状态：FREE → CAPTURING → READY → IN_USE → FREE。显示、Canny、AI 可分别持有引用；存在读者
的帧保持内容不变。首版优先独立的少量帧缓冲与 ROI 缓冲，实际数量由最大占用时长和内存预算确定。
仲裁原则 显示读取与实时采集写入优先，Canny/AI 使用限额或分段突发，防止大任务长期占用总线。
快照与回放 冻结首先固定显示帧，采集是否继续由模式定义；回放优先保存少量关键帧与缺陷 ROI，长时全帧回
放作为容量验证后的增强。
DMA 一致性 帧基地址、stride、格式和长度必须一致；若 CPU 使用缓存，明确 DMA 缓冲的不可缓存区或 
clean/invalidate 规则，并配合内存屏障。
带宽验收
在摄像头、显示、Canny、AI 同时工作时统计峰值队列和读写服务时间。单模块 DDR 测试结果只证明该访问模式，不应直
接等同完整系统吞吐。

何结果用于孔位、轮廓缺口等，模型用于划痕、污点、异物等候选任务；最终类别由真实样本决定。

采用完整整数 INT8 模型作为首版候选。先在软件参考路径验证静态输入，再集成相机 ROI 和硬件加速。官方生

自定义指令只围绕真实瓶颈设计
可评估打包点积、定点重定标、像素打包或特征统计，但先查看 profiling。如果模型主要耗时在卷积，单独加速
很小的全连接层，整体收益可能有限。避免重复实现已由 TinyML 加速器承担的功能。[R6]
量化数学 加速核需覆盖输入/权重偏移、INT32 累加、bias、逐通道尺度、舍入与饱和；不是只完成有符号乘加

评价边界 报告整个预处理+推理+后处理时间，同时给出单算子数据。软件绕过硬件的对照不释放已综合的逻辑

项迁移，不应把参考工程视作即插即用。 [R3]
